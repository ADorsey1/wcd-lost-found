# Rover Search

Easton Area School District Lost and Found System

## Project Info

A web application for managing lost and found items at Easton Area School District.

## Getting Started

### Prerequisites

- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
npm install
npm run dev
```

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- Vite
- shadcn/ui
